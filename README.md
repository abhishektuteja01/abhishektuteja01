Previously Advisory Analyst @ Deloitte · Working at the intersection of data, AI, and financial services.
 
My path started at Deloitte supporting SAP ACM commodity trading and risk systems for a Fortune 100 client — daily mark-to-market reconciliation, transaction-chain defect investigation, and multi-country rollouts. I'm now building on that foundation with data and AI projects applied to finance.
 
---
 
### What I'm Building
 
**[PROVA](https://github.com/abhishektuteja01/PROVA)** — An agentic AI tool that assesses model risk documentation against SR 11-7 guidelines. Covers 20 element codes across Conceptual Soundness, Outcomes Analysis, and Ongoing Monitoring with a weighted scoring system. *(TypeScript, Anthropic API, multi-agent orchestration)*
 
**[CapTrack](https://github.com/abhishektuteja01/CapTrack)** — A portfolio and trade analysis platform with deterministic accounting for multi-asset, multi-currency realized/unrealized P&L. *(Next.js, TypeScript, Supabase)*
 
**[options-pricer](https://github.com/abhishektuteja01/options-pricer)** — Benchmarked Linear Regression, Random Forest, and XGBoost against Black-Scholes on real options data using RMSE and R². *(Python, scikit-learn, XGBoost)*
 
**[abhishektuteja.com](https://abhishektuteja.com)** — My personal portfolio, deployed on Vercel.
