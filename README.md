### What I'm Building

**[PROVA](https://github.com/abhishektuteja01/PROVA)** — A multi-agent LLM system that reviews model risk documentation against the Fed's SR 11-7. Three concurrent agents feed a judge and orchestrator layer that is hardened against adversarial input, and the whole thing ships on an eval harness that fails CI when a prompt change moves scores too far. It covers 20 SR 11-7 element codes with weighted scoring, per-element gap analysis, and a downloadable PDF remediation report. *(TypeScript, Anthropic API, multi-agent orchestration, prompt-injection defense)*

**[CapTrack](https://github.com/abhishektuteja01/CapTrack)** — A trade analytics platform with deterministic, auditable P&L. It handles partial fills, short positions, and multiple currencies, which is where naive trackers tend to break. *(Next.js, TypeScript, Supabase)*

**[options-pricer](https://github.com/abhishektuteja01/options-pricer)** — Benchmarked Linear Regression, Random Forest, and XGBoost against Black-Scholes on real options data using RMSE and R². *(Python, scikit-learn, XGBoost)*

**[abhishektuteja.com](https://abhishektuteja.com)** — My personal portfolio, deployed on Vercel.
