My path started in SAP S/4HANA financial system migrations, where I developed a deep appreciation for how critical systems need rigorous validation. Now I'm channeling that into ML-powered approaches to model risk management.

### What I'm Building

**[Prova](https://github.com/abhishektuteja01/prova)** — An agentic AI tool that assesses model validation documentation against SR 11-7 guidelines. Covers 20 element codes across Conceptual Soundness, Outcomes Analysis, and Ongoing Monitoring with a weighted scoring system.

**[abhishektuteja.com](https://abhishektuteja.com)** — My personal portfolio, deployed on Vercel.
